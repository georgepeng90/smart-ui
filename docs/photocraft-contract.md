# PhotoCraft 制作接口与证据

SmartUI PhotoCraft v0.9.0 使用正常安装的 PhotoCraft v0.20.1 CLI，要求 `--version` 的完整输出为 `photocraft-cli 0.20.1 (327c4cc82, 2026-11-03)`。版本号相同但构建不同也会拒绝执行。通过 `SMARTUI_PHOTOCRAFT_CLI` 指定绝对路径，或使用正常安装位置（例如 `%LOCALAPPDATA%/Programs/ArtCraft/PhotoCraft/photocraft-cli.exe`）和 PATH。执行前查询真实路径、完整版本与文件摘要；应用缺失、版本错误或操作失败明确报错，不自动下载或改用其他制作后端。

## MCP 工具

| 工具 | 参数与结果 |
| --- | --- |
| `photocraft_status` | 无参数；查询真实 CLI 路径、版本及摘要 |
| `photocraft_inspect_document` | `document` 为绝对 `.pcraft` 路径；返回文档及原生节点信息 |
| `photocraft_preview` | `document` 为绝对 `.pcraft` 路径；返回原尺寸 PNG |

组件制作使用项目工具执行，不对外暴露任意原生命令批处理。原生节点 ID 为整数，项目计划使用稳定字符串 key，两者分别记录。

## 执行与失败

程序计划预检不生成成功资产。实际制作记录使用的后端构建、程序与风格版本、计划、原生请求及响应、源文件和 PNG。更新已有组件保留输入源文件，保存并重开输出后检查节点与像素；局部修改还检查未选内容。

候选制作在独立运行目录中完成。发布前在同一项目锁内核对项目版本、当前源文件摘要及运行证据，再替换源文件并登记记录；发布前的冲突不会覆盖原源文件。若发布后项目文件持久化失败，错误会明确说明源文件已发布，并给出候选证据路径，不宣称自动回滚。

超时或失败不意味着没有发生修改。保留运行结果和已完成范围，先核对现场及证据，不自动重发请求或宣称回滚。历史成功记录不证明失败后的当前文件仍然有效。运行证据不能替代实际视觉检查或用户确认。
